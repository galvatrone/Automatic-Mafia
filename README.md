# Automatic Mafia

Первый визуальный этап приложения "Автоматический ведущий мафии": регистрация участников, присвоение стабильных номеров и наблюдение через встроенную камеру ноутбука.

## Что перенесено из `/home/lost/Documents/face-reg`

- логика локальной базы `known_faces.pkl`;
- encodings из `face_recognition`;
- OpenCV-захват камеры;
- асинхронная обработка кадров через отдельные процессы;
- удержание треков между циклами распознавания;
- fallback по позиции после краткой потери лица;
- аккуратное накопление новых encoding и фотографий.

Исходный код и файлы проекта `face-reg` не изменяются. Новый проект самостоятельный и использует собственную базу лиц в `Automatic Mafia/data/known_faces.pkl`.

## Данные

- `data/known_faces.pkl` — локальная копия базы распознавания;
- `data/faces/` — новые лица, добавленные этим приложением;
- `data/players/` — стабильные фотографии карточек участников;
- `data/mafia_session.json` — состав текущей партии: участник, номер, имя и связь с face-id.

Новая сессия сбрасывает только состав партии и номера, но не удаляет базу распознавания лиц.

База лиц общая между партиями. Если человек зарегистрировался в одной игре, в следующей игре он распознаётся по этой базе. Если новый кадр того же человека немного отличается и не конфликтует с похожими лицами, приложение сохраняет дополнительный encoding и фото. Для защиты от раздувания и путаницы есть лимит `MAX_ENCODINGS_PER_FACE`, cooldown добавления, минимальная полезная дистанция и проверка близости к другим людям.

## Архитектурные границы первого этапа

Сейчас реализована только подготовка: камера ноутбука, регистрация, стабильные номера и видимость игроков.

Логические части:

- `automatic_mafia/camera/` — источники камеры;
- `automatic_mafia/vision/` — распознавание, worker-процессы, наблюдения и трекинг;
- `automatic_mafia/storage/` — база лиц и состояние сессии;
- `automatic_mafia/models.py` — постоянные и временные сущности;
- `automatic_mafia/ui/` — Tkinter-интерфейс ведущего.

Основная точка запуска теперь использует PySide6:

- `automatic_mafia/ui/qt_app.py` — два независимых окна: пульт ведущего и игровое табло;
- пульт владеет действиями `GameStore`, регистрацией и камерой;
- табло получает только публичную проекцию текущей фазы и не содержит игровых кнопок или технических статусов.

Будущие подключения:

- жесты и положение головы добавляются в слой зрения рядом с `Observation`;
- обработка выбора цели и подтверждения добавляется между `CameraWorker` и игровым движком;
- роли, ночные действия, голосование и победа добавляются в отдельный игровой движок, который не должен напрямую зависеть от видеокадров;
- публичный игровой экран должен брать только разрешённые данные текущей фазы, не показывая скрытые роли в дневных состояниях.

Для запуска интерфейса нужны зависимости `requirements.txt`, включая `PySide6`.
